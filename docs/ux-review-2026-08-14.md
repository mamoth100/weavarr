# UI/UX review findings - 2026-08-14

Comprehensive review done live against http://10.0.0.254:6767 at 1280px and
375px viewports, cross-checked against component code. Items are checkboxes so
this can work as a punch list; keep status current as things get fixed.

## Critical - mobile-breaking

- [x] **Card actions unreachable on touch** - Favorite/Watched/Sucks buttons in
      `CardActions.tsx` are `opacity-0 group-hover:opacity-100`; verified
      `opacity: 0` at 375px. No hover exists on touch, and the poster is a
      link, so first tap navigates away. The app's core loop (favorite/mark
      watched/thumbs-down while browsing) is impossible on a phone, and the
      actions are undiscoverable. Fix: always-visible on touch
      (`@media (hover: none)` / `pointer-coarse:`) or a per-card "..." button.
      Buttons are also 26x26px - under the ~44px touch-target minimum.
- [x] **Calendar unreadable + dead-end on mobile** - day cells measure 36px
      wide at 375px; chips are 10px font truncated to ~2 letters; episode info
      only exists in a hover `title` tooltip; chips aren't clickable on any
      platform. Fix: agenda/list view below `lg` (date-grouped rows), make
      entries link to the show/movie, collapse repeats ("House of Stassi x3").
- [x] **Settings inputs clipped off-screen on mobile** - fixed `w-52` label +
      `flex-1` input side-by-side; at 375px the input starts at x=265 with
      width 209 (extends to 474 on a 375px viewport). Fix: stack label above
      input below `sm` in the shared row renderer.

## High-impact friction (all platforms)

- [x] **Filter panel closes after every selection** (fixed; note: active
      chips and Reset-all already existed - review miscounted those) - `filtersOpen` client
      state resets because FilterBar remounts (Suspense boundary + router.push
      re-render). Multi-filter = reopen panel per choice. Also: active filters
      invisible when closed (just a count badge), no clear-all.
- [x] **No visible keyboard focus** - `outline: none` app-wide with no
      focus-visible replacement. One global `focus-visible:ring-2
      ring-amber-400` would cover it.
- [x] **Pagination Prev/Next only across 64 pages** - raw `<a href>` full
      reload (inconsistent with client nav everywhere else), scroll reset,
      pager sits below 20 cards. Add numbered/first/last links.
- [x] **"Back to Browse" mislabeled** - it's `router.back()`, goes wherever
      you came from, not Browse. Redundant with sidebar nav anyway. Rename to
      "Back" or drop.
- [x] **Sidebar mixes genres and pages in one flat list** - genres
      (homepage views) look identical to pages (Watch/Status/Library...).
      Add section labels ("Browse" / "Manage") or a divider.
- [x] **Same item in two places with two names** - Watch > "Recently Watched"
      (Clear/Delete) duplicates Status > "Ready to Clean Up" (Delete episode)
      for the identical episode. Pick one home or one name.
- [x] **Library page is a delete list** - only affordance per row is Delete;
      titles don't link to detail pages; no search/sort in a growing list.
- [x] **Hover-only actions are a desktop discoverability problem too** -
      nothing on a card signals actions exist until you happen to hover.
      First-time desktop users won't know favorite/watched/sucks are there.
- [ ] **Filter panel choice overload** - 120 visible buttons when open
      (verified). Genre row alone is ~23 buttons. Consider collapsing rarely
      used groups or a two-level layout. NOT addressed in the 2026-08-14 pass
      - needs its own design thought, not a mechanical fix.

## Accessibility

- [x] **Contrast failures** - `text-zinc-600` on near-black computes to
      ~2.5-3:1, under the 4.5:1 AA minimum for small text; used for real info
      (env-key names, "not set", timestamps, result counts). `text-zinc-500`
      ~4:1 borderline. Bump one shade.
- [x] **Native `title` tooltips carry real content** - calendar episode info,
      disabled Watched Sync reason, deleted-movie reason. Invisible to touch
      and keyboard. Replace with the click-toggle info pattern already built
      for TMDB/OMDb/Trakt.
- [x] **Escape doesn't close** filter panel / drawer / dropdowns - fixed for
      all of them. The drawer focus trap sub-item is still open (minor).
      (aria-labels and poster alt text are already good.)

## Public-release jargon (matters for the GitHub goal)

- [x] "Request (Radarr)" / profile-picker buttons expose internal tool names -
      users shouldn't need to know Radarr exists to click "Add movie".
- [x] Raw env-var names (`TMDB_TOKEN`, `PUSHOVER_NOTIFY_IMPORTS`) as visible
      field subtitles in Settings; "(Pi only)" labels meaningless off this Pi.
- [x] Enable/Disable `<select>` dropdowns where toggle switches are the
      universal pattern.
- [x] "Sucks" is app personality (keep for personal use) but unlabeled mystery
      for strangers - "Not interested" is the clear alternative. Optional.

## Minor polish

- [x] Mobile top bar is a ~53px sticky strip holding only the hamburger -
      could carry the current page title.
- [x] Results info split across two stacked micro-rows ("1,558 results" /
      "14 sucks hidden...") - one line.
- [x] "+26 more" in episode lists reads as expandable but isn't.
- [x] Search: clear button already existed (review miss - text extraction
      couldn't see it). Two-scope search left as-is deliberately.
- [x] Settings "needs a restart" amber banner shows permanently even with
      nothing changed - show only when something's actually pending.
- [ ] Fixed 20-item page size with 1,500+ results - DEFERRED: page numbers
      map 1:1 to TMDB API pages; changing display size needs its own
      pagination redesign, not worth coupling to this pass.

## Already good - don't regress

Two-step inline delete confirms everywhere; consistent zinc/amber theme;
honest empty states; hidden-count transparency; pending-filter pulse;
backup-before-save; safe-area handling; click-outside dismissal patterns;
aria-labels on icon buttons; poster alt text.

## Suggested priority order

1. Touch-visible card actions (unblocks the core loop on mobile)
2. Mobile settings row stacking (small fix, currently broken)
3. Mobile calendar agenda view + clickable entries
4. Filter panel stays open + active-filter chips
5. Global focus-visible + contrast bump (cheap, big a11y win)
6. Numbered pagination
7. Sidebar grouping, Library links/search, jargon pass

## Status

All items fixed and deployed 2026-08-14 except: the deferred page-size item,
the filter-panel choice-overload redesign, and the drawer focus trap.
"Sucks" renamed to "Not interested" (user decision); cleanup sections kept in
both locations but unified into one shared RecentlyWatchedSection component
(user decision); "Request (Radarr/Sonarr)" became "Add Movie"/"Add Show"
(user decision).
